# ПСО — просмотрщик кода

Приложение создаёт короткие ссылки на зашифрованную фамилию для выбранного врача. Открывается по HTTPS без учётной записи ChatGPT или GitHub и добавляется на экран «Домой». Выпуск настроен на отдельный сервис коротких ссылок; его действующая база и API проверены на вымышленных данных.

Одна ссылка предназначена одному получателю. Фамилия и необязательная отметка «ОРИТ» шифруются на телефоне; получатель видит их на 30 секунд. При уходе из приложения результат скрывается.

**Рабочий бот Пачки и больничные отчёты этим выпуском не меняются.** Здесь реализован ручной обмен. Приложение не получает список участников чатов.

## Подключение телефона

1. Откройте адрес просмотрщика в Safari на iPhone → «Поделиться» → «На экран “Домой”». На Android в Chrome выберите «Установить приложение» или «Добавить на главный экран».
2. Запустите просмотрщик с синего значка. «Проверить этот телефон» открывает вымышленный пример на этом же устройстве.
3. В «Контакты врачей» создайте открытую карточку и передайте её коллеге. Если карточка уже создана, используйте прежнюю: обновление сохраняет ключи и контакты.
4. Взаимно добавьте карточки, предварительно сверив полный контрольный код лично или по известному номеру телефона. Карточка содержит выбранное имя врача и открытые ключи, без закрытого ключа и фамилий пациентов.
5. Для **создания коротких ссылок** администратор один раз подключает эту же открытую карточку к сервису. Передайте ему карточку. Создание до подключения будет отклонено; телефон, который только получает ссылки, в этот список добавлять не нужно.
6. Проверьте обмен между двумя телефонами на вымышленной фамилии.

Реальные карточки отправителей пока не подключены. Для действующих пользователей повторный обмен прежними карточками и пересоздание ключей не требуются.

## Отправка и открытие

В «Создать ссылку» введите фамилию, выберите получателя, подпись и срок — 1, 4 или 24 часа. Доступны подписи «Новый пациент», «Новый пациент ОРИТ» и «Проверочная история». Первые две согласованы с отметкой ОРИТ в зашифрованной записи. Проверочная подпись меняет только текст: вымышленную фамилию нужно ввести самостоятельно.

«Скопировать ссылку» копирует подпись и настоящий короткий адрес отдельной строкой. Ссылка имеет вид `https://…/pso-code-viewer/#r=<22 символа>` и на настроенном адресе GitHub Pages занимает 67 символов. Оформление буфера обмена не требуется. Вставьте сообщение в Пачку и при необходимости добавьте комментарий. Подпись и комментарий видны в чате и не шифруются просмотрщиком.

Получатель копирует ссылку или всё двухстрочное сообщение, открывает синий значок и нажимает «Вставить и открыть». При запросе iPhone нужно разрешить вставку. Есть поле для ручной вставки. Буфер читается только по нажатию кнопки.

Если ссылка открыла браузер, нажмите «Скопировать для приложения», затем перейдите в просмотрщик со значка. Браузер и установленное приложение могут иметь разные хранилища ключей; сайт не может гарантированно переключить iPhone в установленное приложение.

Создание и открытие коротких ссылок требуют интернета. Оболочка может запускаться без сети, а прежние полные ссылки `#pso=…` остаются совместимыми. Ошибка сервиса не выдаётся за успешно созданную ссылку. Лимиты новых ссылок: 10 за минуту и 200 за сутки на телефон, 5000 за сутки для всех отправителей. Счётчики используют время сервера UTC.

## Обновление и ключи

Откройте просмотрщик с интернетом, полностью закройте приложение и его вкладки и откройте снова. Новый offline-кэш активируется после закрытия прежних окон. **Не удаляйте данные сайта:** в них находятся ключи и контакты.

Выпуск сохраняет существующий origin, путь, хранилище ключей, карточки `PSO-CARD1.…` / `#card=…` и ссылки `#pso=…`. На другом домене или пути прежние ключи автоматически не переносятся. Экспорт и восстановление закрытых ключей не реализованы.

## Размещение

Публикуется только `docs/` как статический HTTPS-сайт. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/docs`. Область установки и ресурсы остаются относительными. Версия кэша — `github-v6-short-links`.

Отдельный проект Supabase: `spugfikalpihorcwcdqc`. Настроенный публичный endpoint:

`https://spugfikalpihorcwcdqc.supabase.co/functions/v1/pso-shortlinks`

CSP разрешает соединение со своим сайтом и точным origin сервиса. Клиент не содержит пароль базы, service-role key или токен Пачки. Развёртывание, права, лимиты, очистка и подключение карточек описаны в [server/DEPLOY.md](server/DEPLOY.md). Настройка выпуска сама по себе не подтверждает его публикацию в GitHub Pages.

В публичный репозиторий нельзя добавлять реальные отчёты, карточки врачей, записи списка разрешённых отправителей, закрытые ключи или секреты доступа.

## Границы защиты

- Сервис хранит подписанный шифротекст, сроки, хеш случайного идентификатора и идентификатор открытого ключа отправителя. Расшифрованная фамилия и закрытые ключи на сервис не передаются. Сервис может наблюдать время создания и обращения к ссылкам.
- Создание разрешается подключённым устройствам по цифровой подписи. Получение шифротекста использует случайный 128-битный идентификатор. Для расшифровки нужны ключ получателя и проверенная карточка отправителя.
- Сервер прекращает выдачу по истечении срока; ежеминутная очистка удаляет просроченные записи из рабочей таблицы. Это не гарантирует удаление из резервных копий провайдера или с устройств получателей. Скрытие через 30 секунд не запрещает скриншот.
- Удаление контакта или запрет создания новых ссылок не отзывает уже полученную информацию. Автоматического управления доступом по членству в чатах нет.
- Закрытые ключи WebCrypto неэкспортируемые, но изменённый код с доступом к origin может ими пользоваться. Доверие к хостингу и аккаунту публикации необходимо. Проектные сайты одного аккаунта GitHub Pages разделяют origin; разделение по пути не защищает от их кода.
- Публичный сайт может установить любой человек с адресом. `noindex` не ограничивает доступ. Шифрование не означает юридически гарантированное обезличивание или соответствие требованиям к медицинским информационным системам. Независимый аудит не проводился.

## Проверка

```sh
node --experimental-vm-modules --test tests/*.test.mjs server/*.test.mjs
```

Локальный набор: 73 теста прошли. Проверены криптография, совместимость прежних ссылок, короткие ссылки через реальный клиент и обработчик с тестовым хранилищем, очистка интерфейса, ошибки и границы offline-кэша.

На действующем сервисе прошли HTTP-проверки создания, разрешения и расшифровки, обеих подписей, неверного получателя, неизвестного/отключённого отправителя, повторов, конфликтов, сроков, CORS и размера запроса. Из 12 одновременных запросов приняты ровно 10, ещё 2 ограничены. Просроченная запись возвращала 404 и затем была удалена заданием Cron. SQL-проверки и запуск Cron также прошли.

Эти результаты не подтверждают поведение нового выпуска в нативной Пачке и на реальных iPhone/Android. После подключения карточек нужна проверка вымышленной ссылки между телефонами.
