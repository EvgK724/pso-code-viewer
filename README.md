# ПСО — просмотрщик

Установленное веб-приложение для открытия зашифрованных сообщений из двух чатов Пачки. Адрес и ключи существующих телефонов сохраняются: https://evgk724.github.io/pso-code-viewer/.

## Кто что делает

| Участник | Действия |
|---|---|
| Бот на больничном компьютере | По сохранённым ежедневным отчётам создаёт «Новый пациент»; для поступившего в ОРИТ — «Новый пациент ОРИТ» в чате кардиолога |
| Невролог | Создаёт «Проверочную историю» для кардиолога или реаниматологов |
| Кардиолог | Открывает сообщения группы кардиолога |
| Реаниматолог | Открывает сообщения группы ОРИТ |
| Администратор | Приглашает врачей, подтверждает их телефоны, отзывает доступ; может создавать проверочные истории |

Администратор и неврологи не добавляются к получателям автоматически. В группе кардиолога допускается один действующий получатель. В группе ОРИТ — утверждённые реаниматологи. Приложение ведёт собственный список доступа: состав чатов Пачки автоматически не синхронизируется.

## Подключение

1. Администратор открывает существующий просмотрщик с синего значка, указывает имя и роль врача, создаёт приглашение и лично передаёт ему ссылку.
2. Врач открывает просмотрщик с экрана «Домой» и активирует приглашение. Если ссылка открылась в Safari, нужно скопировать приглашение и вставить его в существующем приложении, чтобы использовать прежний ключ.
3. Заявка ожидает подтверждения. Администратор сверяет контрольный код телефона по известному каналу и подтверждает конкретного врача. Пересылка приглашения сама по себе доступа не даёт.
4. Для уведомлений врач нажимает «Включить уведомления», разрешает их и выполняет проверку. Уведомления содержат только общий текст. Нажатие открывает нужную запись в установленном просмотрщике.

Приглашения одноразовые и ограничены по сроку. Закрытые ключи остаются на телефонах. Не удаляйте значок и данные сайта для обновления: откройте приложение с интернетом, закройте его и вкладки просмотрщика, затем откройте снова.

## Отправка

Вручную доступна только «Проверочная история». Невролог вводит фамилию, выбирает группу получателей и срок, создаёт ссылку, затем копирует её в соответствующий чат вместе с комментарием. Фамилия шифруется на телефоне отдельно для каждого действующего получателя выбранной группы. Один короткий адрес позволяет каждому из этих врачей получить только свою зашифрованную копию.

Новые поступления отправляет только бот. Обновление сайта не обновляет программу на больничном компьютере: необходимо установить новый пакет бота и подтвердить его собственный ключ с ролью «Бот». Пакет сохраняет настройки отчётов и историю отправок. При ошибке шифрования или отсутствии утверждённых получателей фамилия и её маска в чат не отправляются.

Правила отчётов остаются прежними: поступление в ПСО → оба чата; поступление в ОРИТ → кардиолог с отметкой ОРИТ; перевод в ПСО из других отделений → оба чата, кроме переводов из ОРИТ. Бот читает сохранённые файлы, подтверждает изменения двумя чтениями и отправляет с 07:00 до 22:00 по Челябинску. Он не изменяет отчёты.

## Открытие

Нажатие уведомления просмотрщика открывает приложение. Ссылка из Пачки может открыться в браузере: в этом случае скопируйте её, откройте синий значок и нажмите «Вставить и открыть». После проверки роли, ключа получателя и подписи фамилия показывается на 30 секунд и скрывается при уходе из приложения.

Старые ссылки остаются читаемыми прежним получателем с прежними проверенными карточками. Новые сообщения используют роли и группы. Для коротких ссылок нужен интернет; оболочка приложения может открываться без сети.

## Защита и её границы

- Сервер получает отдельные подписанные шифротексты, открытые карточки устройств, роли и служебные сроки. Фамилия расшифровывается на телефоне получателя. Общего закрытого ключа группы нет.
- Создание сообщения проверяется сервером: поступления — только от бота, проверочные истории — от невролога или администратора. Сервер проверяет полный текущий состав получателей.
- Отзыв доступа запрещает получение новых записей и последующее разрешение групповых ссылок. Он не удаляет уже скачанные копии и не запрещает скриншот.
- Ключи WebCrypto неэкспортируемые, но код того же origin может ими пользоваться. Аккаунт публикации и хостинг должны оставаться защищёнными. Другие проекты одного аккаунта GitHub Pages разделяют origin.
- Подпись ссылки и комментарий в Пачке видны участникам чата и не шифруются просмотрщиком.
- Уведомление, принятое службой доставки, не подтверждает прочтение врачом. Отправка зависит от сети, разрешений и настроек телефона.
- Шифрование и ограничение доступа не означают юридически гарантированное обезличивание или сертификацию медицинской системы.

## Разработка и проверка

Статически публикуется только каталог `docs/`. Не добавляйте в репозиторий реальные отчёты, карточки врачей, секреты, токены Пачки или закрытые ключи. Серверная схема и порядок развёртывания описаны в `server/DEPLOY.md`.

```sh
node --experimental-vm-modules --test tests/*.test.mjs server/*.test.mjs
```

SQL-проверки выполняются отдельными сценариями с откатом тестовых записей. Автоматические тесты не заменяют проверку уведомления и обмена вымышленной записью между действующими телефонами.
