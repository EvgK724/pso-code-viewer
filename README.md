# ПСО — просмотрщик кода

Статическое приложение для создания и просмотра зашифрованных ссылок для выбранного врача. Открывается по публичной HTTPS-ссылке без учётной записи ChatGPT или GitHub. Может добавляться на главный экран телефона; установщик и магазин приложений не требуются.

## Что работает

- Ручное создание ссылки из фамилии и необязательной отметки «ОРИТ».
- Одна ссылка предназначена одному выбранному получателю. Для другого врача нужна отдельная ссылка.
- Шифрование на открытый ключ получателя и проверка подписи отправителя.
- Подтверждение контрольного кода публичной карточки перед добавлением врача.
- Просмотр на 30 секунд, скрытие при уходе из приложения.
- Сохранение ключа и контактов на устройстве, работа установленной оболочки без сети после её загрузки.
- Инструкция для короткой ссылки в редакторе Пачки; полная ссылка, форматированное копирование и прежняя карточка также доступны. Шифротекст и контрольный код сохраняются целиком.
- Перенос входящей ссылки из браузера в установленный просмотрщик: «Скопировать для приложения» → синий значок → «Вставить и открыть».

**Интеграция с ботом Пачки и больничными отчётами в этот выпуск не входит.** Приложение не проверяет членство в чатах. Не меняйте формат сообщений рабочего бота, пока совместимость с этим форматом отдельно не проверена.

## Подключение телефона

1. Откройте опубликованную ссылку в Safari на iPhone. Выберите «Поделиться» → «На экран “Домой”». На Android откройте её в Chrome и выберите «Установить приложение» или «Добавить на главный экран».
2. Откройте приложение с нового синего значка. Нажмите «Создать тестовый код» и проверьте вымышленную фамилию.
3. В «Контакты врачей» создайте свою карточку и передайте её коллеге. Карточка содержит ваше выбранное имя и открытые ключи, без закрытого ключа и фамилий пациентов.
4. Взаимно добавьте карточки. Сверьте контрольные коды лично или по известному номеру телефона и только затем подтвердите добавление.
5. Проверьте обмен между двумя телефонами на вымышленных фамилиях. Ссылку для коллеги можно скопировать в нужный чат.

Ссылка из мессенджера может открыться в браузере, который использует другое хранилище ключей. На такой странице нажмите «Скопировать для приложения», откройте установленный просмотрщик с синего значка и нажмите «Вставить и открыть». Поддерживаются и ссылки на фамилии, и карточки врачей; карточка по-прежнему требует проверки. Приложение читает буфер только при нажатии кнопки, не при запуске или возврате на экран. iPhone может запросить разрешение на вставку. При отказе доступна обычная ручная вставка.

Текущий статический сайт не может принудительно переключить iPhone из Пачки в Home Screen web app. Параметр `display: standalone` задаёт запуск со значка, но не реализует Universal Links нативного iOS-приложения. Изменение ссылки или сокращение её подписи это не решает. Ключи между браузером и установленным просмотрщиком не копируются.

## Компактные сообщения

После создания ссылки или своей карточки нажмите «Скопировать адрес для Пачки». В Пачке напишите «Открыть фамилию» (для карточки — «Карточка врача»), выделите слова, откройте меню форматирования «Аа» → ссылку (🔗) и вставьте полный адрес. Так короткая подпись задаётся в самом редакторе Пачки.

Форматированное копирование сохранено в дополнительных способах: оно записывает HTML-ссылку с короткой подписью и полный адрес для приложений, принимающих только обычный текст. На проверенном пользователем iPhone Пачка вставляет длинный адрес, поэтому этот способ не предлагается как основной. Пачка документирует вставку ссылки через своё меню: https://pachca.com/help-center/features/message-formatting. Автоматические тесты не подтверждают поведение её нативного редактора.

Ссылка `#card=…` содержит ту же открытую карточку, что прежний текст `PSO-CARD1.…`. Она только открывает предварительную проверку: врач не добавляется без сверки полного контрольного кода и явного подтверждения. Прежние карточки, ключи устройства и зашифрованные ссылки совместимы с обновлением.

Для обновления откройте приложение с интернетом, затем полностью закройте его и вкладки просмотрщика и откройте снова. Обновление offline-кэша активируется после закрытия старых окон. Не удаляйте данные сайта: там находятся ключи и контакты.

Публичную страницу может открыть и установить любой человек, получивший адрес. Установка «только по ссылке» не ограничивает доступ кругом врачей. Расшифровка требует ключа выбранного получателя и проверенной карточки отправителя. `noindex` и `robots.txt` лишь просят поисковики не индексировать страницу, а не защищают доступ.

## Переход со старого адреса

На новом домене создаются новые ключи и карточки: браузер не переносит их с другого домена. Нужен повторный обмен карточками. Старые ссылки автоматически не расшифруются; для них сохраните прежний просмотрщик и его данные. Переименование каталога приложения также меняет область хранения в этой версии.

Не удаляйте данные браузера или приложение с нужным ключом. Восстановление закрытых ключей и перенос их между устройствами здесь не реализованы. Обновление файлов на прежнем домене и пути сохраняет ключи.

## Размещение

Публикуйте только содержимое `docs/` как статический HTTPS-сайт, например через GitHub Pages. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → `main` → `/docs`. Сборка, workflow GitHub Actions и внешние зависимости не требуются. Одинаковый выпуск работает как в корне домена, так и в каталоге `/pso-code-viewer/`: адреса ресурсов, manifest, service worker и создаваемые ссылки относительные. Синяя иконка включена в выпуск.

В репозиторий не включены записи пациентов, отчёты, токены Пачки, персональные карточки, закрытые ключи или история прежнего размещения. Не добавляйте их в репозиторий при публикации.

Для размещения с чувствительными данными нужен отдельный доверенный origin. Проектные сайты одного аккаунта GitHub Pages обычно разделяют origin `имя.github.io`. Их JavaScript потенциально имеет доступ к хранилищам этого origin. Разделение имён IndexedDB и кэшей по пути предотвращает случайные конфликты, но **не изолирует** от другого кода с того же origin. Отдельный домен либо аккаунт, используемый только для этого приложения, уменьшает этот риск.

## Границы защиты

Это пилот для ручного обмена, без независимого аудита безопасности и без утверждения о соответствии требованиям к медицинским информационным системам.

- Закрытые ключи RSA-OAEP 3072 / ECDSA P-256 создаются средствами WebCrypto как неэкспортируемые и сохраняются в IndexedDB. Неэкспортируемость не мешает вредоносному коду с доступом к этому origin использовать ключ.
- Фамилия и отметка «ОРИТ» зашифрованы; шифротекст находится во фрагменте URL `#pso=`, который браузер не включает в обычный HTTP-запрос. Мессенджер получает отправленную в чат ссылку целиком. Сам сайт не отправляет фамилии на сервер, не использует аналитику и не хранит фамилии в постоянном хранилище.
- Публичный хостинг и аккаунт публикации должны оставаться доверенными: изменённый код приложения может получить доступ к открытым данным. HTTPS и криптография внутри страницы не защищают от подмены самого приложения его издателем.
- Скрытие через 30 секунд не запрещает скриншот и не уничтожает уже полученную информацию. Срок ссылки проверяется по часам устройства; это не гарантированное удаление или серверный отзыв.
- Удаление контакта не отзывает ранее созданные ссылки. Общая ссылка для всех участников чата, автоматическое управление списком врачей и удалённый отзыв доступа отсутствуют.
- Шифрование и замена фамилии ссылкой сами по себе не означают юридически гарантированное обезличивание.

## Проверка

Требуется Node.js с WebCrypto и поддержкой VM Modules:

```sh
node --experimental-vm-modules --test tests/*.test.mjs
```

Проверяются шифрование и подпись, повреждённые и просроченные пакеты, неверный получатель, обязательное подтверждение карточки, двусторонний интерфейсный обмен, скрытие, сохранение устройства между экземплярами тестового интерфейса, пути GitHub Pages и границы offline-кэша. DOM и адаптер хранилища в интерфейсных тестах имитируются. Эти тесты не заменяют проверку IndexedDB, установки, буфера обмена и открытия ссылок на реальных iPhone/Android.
