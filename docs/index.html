Если подключали врачей через синий значок на экране «Домой», откройте ссылку там. Браузер может использовать другой ключ.

Затем откройте синий значок «ПСО Код» → «Вставить и открыть». Эта страница не может сама переключить iPhone в установленный просмотрщик.

Вставьте ссылку в нужный чат Пачки и допишите комментарий. Комментарий в чате этим просмотрщиком не шифруется.

Добавляйте только врачей из ваших чатов. Сверьте контрольный код лично или по известному номеру телефона.

Добавить на экран «Домой»

Приложение открывается по публичной ссылке. Установка не требует ChatGPT, GitHub или пароля.

  1. Откройте эту страницу в Safari.
  2. Нажмите «Поделиться» → «На экран “Домой”» и добавьте значок.
  3. Откройте просмотрщик через новый значок. Создайте тестовый код и карточку для коллег уже в нём.

Если раньше вы пользовались просмотрщиком на другом адресе, создайте здесь новую карточку и обменяйтесь ею с коллегами. Старые ключи автоматически не переносятся; старые ссылки открывайте в прежнем просмотрщике.

На Android откройте страницу в Chrome и выберите в меню «Установить приложение» или «Добавить на главный экран».

Браузер и приложение с домашнего экрана могут хранить разные ключи. Если ссылка открылась не там, скопируйте её и вставьте в тот просмотрщик, где создавали свою карточку.

Бот и больничные отчёты пока не подключены. Состав чатов Пачки автоматически не проверяется.
